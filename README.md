# User Management Dashboard

A full-stack User Management Dashboard built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## 🚀 Live Demo

### Frontend
https://user-mane-db.netlify.app

### Backend API
https://user-management-dashboard-fwv4.onrender.com

## 📌 Features

- View all users
- Add new users
- Edit existing users
- Delete users
- Search users
- Responsive dashboard interface
- REST API
- MongoDB database integration
- Frontend and backend deployed separately

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- CORS
- dotenv
- Mongoose

### Database
- MongoDB Atlas

### Deployment
- GitHub
- Render
- Netlify
